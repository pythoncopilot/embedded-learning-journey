# 🚀 Embedded Systems Learning Journey (30 Days)

This repository documents a structured 30-day hands-on journey into **Embedded Systems, IoT, and Edge Computing**.

Each day builds a complete working project, gradually evolving from basic hardware control to full IoT systems with data analytics and automation.

---

# 🎯 Learning Goals

- Master Arduino fundamentals and hardware control
- Learn Raspberry Pi GPIO programming with Python
- Build real-world IoT systems with sensors and actuators
- Develop web-based IoT dashboards and APIs
- Work with databases for real-time data logging
- Explore edge AI concepts using TensorFlow and Jetson Nano
- Learn CI/CD and DevOps integration for embedded systems

---

# 🧱 Project Structure

- Each day is a separate project repository
- Each project builds on previous knowledge
- Code, dashboards, and system architecture evolve daily
- Documentation improves progressively with each stage
